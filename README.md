# Roteiro de Práticas 02 - Calculadora Científica

O roteiro tem como objetivo principal criar um programa que simule as operações realizadas em uma calculadora científica.
Suas atividades são incrementais, em que o primeiro código representa um MVP e os códigos subsequentes representam atualizações das entregas anteriores.
Os códigos seguem um roteiro fixo criado pelo professor.

**Nenhuma IA foi utilizada neste desenvolvimento.**

## Etapas de desenvolvimento

Etapa 1: Implementação das Operações Básicas [*calculadora_etapa1.py*]

  > Implementa Adição, subtração, multiplicação e divisão, assim como a entrada de dados do usuário.

Etapa 2: Refatoração com Funções para Operações Básicas [*calculadora_etapa2.py*]

  > Transforma as operações em funções para melhor organização.

Etapa 3: Validação de Entrada do Usuário [*calculadora_etapa3.py*]

  > Captura e tratamentos de erros, como por exemplo divisão por zero.

Etapa 4 - Implementação das Operações Científicas [*calculadora_etapa4.py*]

  > Implementa potenciação, radiciação, seno, cosseno, tangente e logaritmo.
